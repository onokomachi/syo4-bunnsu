## 2. 定義を構成する条件と、その反例（複数条件の AND）

**帯分数** ＝「①整数 ＋ ②真分数（分子＜分母）」。**仮分数→帯分数** は「①分子÷分母の商が整数 ②あまりが分子 ③分母はそのまま」のAND。
**帯分数→仮分数** は「①整数×分母 ②＋分子 ③分母はそのまま」のAND。**分母が同じたし算・ひき算** は「①分母はそのまま ②分子だけ計算 ③分数の部分が1をこえたらくり上げ／ひけなければくり下げ」のAND。

| 条件 | 落とした反例 | 問題の場所 |
|---|---|---|
| 帯分数の分数部分は真分数 | 2と9/8（くり上げない） | 判定 `equiv`（まちがいに数えず「1を整数にくり上げよう」）、`add-carry`、`eh-carry` |
| 商とあまりの位置 | 17/5＝2と3/5（商とあまりを入れかえ） | `hen-mixed` `hen-div` の診断、`eh-tomix` |
| 整数×分母 | 3と2/9＝5/9（整数と分子をたす） | `hen-imp` の診断、`eh-toimp` |
| 分母はそのまま | 2/5＋4/5＝6/10 | `add-*` `sub-*` の診断、`eh-den` |
| くり上げ | 2と5/8＋4/8＝2と1/8（1を落とす） | `add-carry` `add-one` の診断、`eh-carry` |
| くり下げ | 5と2/7－4/7＝5と2/7（逆にひく） | `sub-borrow` の診断、`eh-borrow` |
| 整数を分数に直す | 3－3/5＝2と3/5 | `sub-from` の診断、`eh-whole` |

## 6. けいさんらん（kit の FractionPad）

4年は分母が同じなので、通分・約分の道具は出さない。使う道具は **convert（仮分数・帯分数）** と **borrow（くり下げ）** だけ。

| 出す | 道具（先頭が開いたときの道具） | 理由 |
|---|---|---|
| `hen-mixed` `hen-imp` `hen-div` | convert（問題の数を入れて開く） | 分子÷分母・整数×分母＋分子を書いて確かめる |
| `add-basic` `add-carry` `add-one` `wp-add` | convert | 答えの仮分数を帯分数に直す・くり上げ |
| `sub-borrow` `sub-from` | borrow（問題の帯分数・整数を入れて開く） | 1 くり下げて分数に直す |
| `wp-sub` `wp-rem` | borrow, convert（数は入れない。立式は子どもの仕事） | くり下がりがある文章題 |
| `cmp-order` | convert | 仮分数を帯分数・整数に直してくらべる |

出さない: `hyo-*`（図そのものが道具）、`eq-*`（数直線が道具）、`cmp-same` `cmp-num`（直す数が小さい）、`add-mixed` `add-whole` `sub-basic` `sub-mixed` `sub-whole`
（くり上がり・くり下がりが無く、分子のたし算・ひき算だけ）、`add-fig`（図が道具）、`wp-prog`（考えを順にならべる問題）。
採点しない・はじめは閉じている。

## 7. 解答方法の工夫
- **文章題の式は組み立てる（`Ans.kind='build'`。wp-add / wp-sub / wp-rem / wp-prog の式の段）**: 問題文の数のカード（分数・帯分数は縦書き）と ＋ － × ÷ のカード、
  さらにダミーの数のカード（問題文に出てこない数）を1〜3枚まぜる。数のカードは1回ずつ。たし算は順番の入れかえ（3/4＋2と2/4 と 2と2/4＋3/4）も正解、
  ひき算は順番が意味を変えるので正しい順だけ。声かけ: ＋－のとりちがえ／大小（ひかれる数とひく数）のとりちがえ／数のぬけ／ダミーの使用／×÷／しきになっていない。
  **足場の出し方**: 練習は組み立てが基本。同じ手順で2回まちがえたら、「えらぶ」（3つの式）を足場として出す（組み立てる欄は消さない）。
  その項目の熟達バーが 0.6 以上（3回連続ノーミス以上）なら、足場は出さない。**本番テストと実力の階段は組み立てだけ**（足場なし）。**ボス戦は「えらぶ」のまま**。
- 答えが帯分数でも仮分数でもよい問いは、入力欄の上の「仮分数」「帯分数」「整数」ボタンで形を選ぶ（はじめは問いに合わせた形）。
  分母のちがう等しい分数（6/5 のかわりに 12/10）は、まちがいに数えず「問題の分母のままで」と返す。
- 本番テスト：答え1つの問題は2回で×・次へ／全問に「わからない」／一発正解のみ得点／終了後に まちがえた問題へ「やり方」＋「れんしゅうする」。
- 記録：`useRoundRecorder`（まちがえた回数・とちゅうでやめたこと）。
- ヒントは3段。1回目から答えを見せない（verify が検査）。誤答診断は `guard` でくるみ、正解を入れたら必ず出ない（verify が検査）。
- 各項目 20通り以上（verify が数える）。
