# 分数ランド4｜1より大きい分数（syo4-bunnsu）

小4 算数「10. 分数」（東京書籍『新しい算数4下』）の学習アプリ。学級ポータルの単元アプリ（app_id `bunsuu4`）。

- 1より大きい分数（真分数・仮分数・帯分数、テープ・水のかさ・数直線）
- 仮分数と帯分数・整数のなおし方
- 大きさの等しい分数（数直線）・分数の大小
- 分母が同じ分数のたし算・ひき算（帯分数・くり上がり・くり下がり・整数－分数）
- ことばの問題・エラーハンター・本番テスト（紙のテストと同じ大問・配点）・実力の階段・ボス戦

## 開発
```
npm install
npm run dev
npm run check   # ルール点検・型チェック・問題データの検査・ビルド
```
設計は `docs/DESIGN.md`。
